# Invoice Generator

A quick and elegant **Invoice Generator** app built with **React**.  
Easily create, preview, and export invoices with a clean and modern UI.

Created by Aritra Das
---

## 🚀 Features
- ✨ Simple and intuitive interface   
- 📝 Add client details, line items, tax, and discounts  
- 💱 Currency selection support  
- 📄 Export/Print invoices in PDF

---

## 🛠️ Tech Stack
- **React** (Frontend framework)  
- **React-Bootstrap** (UI components & styling)
